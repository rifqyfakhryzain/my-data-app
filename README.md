# MyDataApp

MyDataApp adalah aplikasi Android sederhana yang dibuat menggunakan Java dan Android Studio untuk mengelola data mahasiswa.

Project ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS) Mata Kuliah Pemrograman Android.

## Features

* Login Authentication
* Validasi Login Hardcode
* Session Login menggunakan SharedPreferences
* Auto Login Session
* Logout Feature
* Form Input Data Mahasiswa
* Menampilkan Data Mahasiswa menggunakan ListView
* Penyimpanan Data Lokal menggunakan SharedPreferences

---

## Tech Stack

* Java
* Android Studio
* XML Layout
* SharedPreferences
* ListView
